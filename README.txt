adiinnoVation — ONE WEEK · ONE COMPLETE TOPIC

HOW TO RUN
1. Extract the ZIP file.
2. Open index.html in a modern browser, or host the folder on a static web host.
3. Choose English or മലയാളം from the language selector in the top header.
4. Complete the ten lesson sections at your own pace during the week and score at least 80% in the final assessment.
5. Select Complete this week’s topic, then Generate certificate.
6. Enter the complete name exactly as it should appear and select Generate & download certificate.

CERTIFICATE
- Generated locally in the browser as a downloadable PNG image.
- Includes the learner's entered name, topic name in English, final assessment score, learning duration, date, and adiinnoVation branding with the V in red.
- The certificate heading reads ONE WEEK · ONE COMPLETE TOPIC.

OTHER FEATURES
- Weekly learning topic: Communication Skills & Spoken English, with ten lessons covering communication foundations, spoken English, grammar and vocabulary, listening and pronunciation, everyday conversations, a weekly speaking challenge, final quiz, bilingual learning games, weekly progress tracking, and PWA support.
- Learning progress is stored locally in this browser on this device only; it is not uploaded or stored online.
- No My Learning Notes or Save My Notes section is shown.
- Footer groups: “Need help?” with WhatsApp icon only; “Follow us” with Instagram and YouTube icons; “Visit website” with website icon. The WhatsApp phone number is not displayed in the app.
- Audio uses the browser's built-in speech synthesis. Malayalam audio requires a Malayalam (ml-IN) voice installed/enabled on the device.
- No YouTube video-learning section is included; the YouTube icon in the footer links to the AdiInnovation channel.

NOTE
This app is a front-end learning prototype. Weekly progress is stored in browser storage and is device/browser-specific. Clearing browser data may clear saved progress.
