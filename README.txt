adiinnoVation — One Day · One Complete Topic

HOW TO RUN
1. Extract the ZIP file.
2. Open index.html in a modern browser, or host the folder on a static web host.
3. Choose English or മലയാളം from the language selector in the top header.
4. Complete all five lesson sections and score at least 80% in the final assessment.
5. Select Complete today's topic, then Generate certificate.
6. Enter the complete name exactly as it should appear and select Generate & download certificate.

CERTIFICATE
- Generated locally in the browser as a downloadable PNG image.
- Includes the learner's entered name, today's topic, final assessment score, learning duration, date, and adiinnoVation branding with the V in red.
- No place, physical signature, WhatsApp submission, or server account is required.

OTHER FEATURES
- Today’s focused topic: Knowledge in Artificial Intelligence & Generative AI. Includes five lessons, practical challenge, notes, final quiz, learning games, progress tracking, and PWA support.
- Learning progress and notes are stored locally in this browser on this device only; they are not uploaded or stored online.
- Certificates are generated in the browser and downloaded to the device. The app does not upload or store certificate files online.
- Audio uses the browser's built-in speech synthesis. Malayalam audio requires a Malayalam (ml-IN) voice installed/enabled on the device.
- No YouTube/video section is included.

NOTE
This app is a front-end learning prototype. Local browser storage is device/browser-specific; clearing browser data may clear saved progress.
